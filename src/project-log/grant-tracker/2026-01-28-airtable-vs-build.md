Spent a week evaluating whether to build this from scratch or configure something existing.

![Options compared](./comparison.png)

Building it means full control over the data model but also owning auth, permissions, and a UI that non-technical staff can actually use. Configuring an existing tool gets those for free and loses flexibility on reporting.
